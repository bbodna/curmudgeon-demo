# curmudgeon-demo

Playable demo of **Curmudgeon: Bludgeon Legend**, a mobile-first 3D arcade roguelite about a grumpy old man defending his morning walk.

Play it: https://bbodna.github.io/curmudgeon-demo/

Drag (or A / D) to move. Attacks are automatic. Space or the big button fires GET OFF MY LAWN! when the Grumpiness meter allows.

This repository holds built files only. Source lives in the private `curmudgeon-bludgeon-legend` repository and is published here with `npm run demo`.
